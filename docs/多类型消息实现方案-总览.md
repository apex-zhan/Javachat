## 🚀 实战练习

### 练习1：新增名片消息

**需求：**
用户可以发送名片消息，包含：
- 姓名
- 头像
- 个人简介
- 联系方式

**任务：**
1. 定义枚举：`BUSINESS_CARD(11, "名片消息")`
2. 创建Req、DTO、Resp
3. 实现BusinessCardMsgHandler
4. 编写测试用例

**预计时间：** 10-15分钟

---

### 练习2：消息编辑功能

**需求：**
- 文本消息可编辑
- 保留编辑历史
- 通知已读用户

**任务：**
1. 设计数据库表（message_edit_history）
2. 在AbstractMsgHandler中添加canEdit()方法
3. TextMsgHandler实现编辑功能
4. 编写测试

**预计时间：** 30-40分钟

---

### 练习3：AI生成消息

**需求：**
集成ChatGPT，@AI机器人自动回复

**任务：**
1. 创建AIMsgHandler
2. 集成ChatGPT API
3. 在TextMsgHandler中触发AI回复

**预计时间：** 40-60分钟
