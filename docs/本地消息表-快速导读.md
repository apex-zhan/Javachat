## 🎨 核心原理速览

### 问题场景

```java
// ❌ 问题代码
@Transactional
public void sendMessage() {
    messageDao.save(message);  // DB操作
    mqProducer.send(message);   // MQ发送
    // 问题：MQ失败，DB已提交 → 数据不一致
}
```

### 解决方案

```java
// ✅ 本地消息表方案
@Transactional
public void sendMessage() {
    // 1. 保存消息到DB
    messageDao.save(message);
    
    // 2. 调用带@SecureInvoke的方法
    mqProducer.sendSecureMsg(message);
    // → AOP拦截
    // → 序列化方法信息
    // → 保存到secure_invoke_record表（同一事务）
    // → 事务提交
    // → 异步执行MQ发送
    // → 失败自动重试
}

@SecureInvoke(maxRetryTimes = 5, async = true)
public void sendSecureMsg(Message message) {
    rocketMQTemplate.send(topic, message);
}
```

## 🔍 问题索引

### Q1: 为什么不直接在事务内调用MQ？

**答案位置**：第二章 2.1节

**核心要点**：
- 本地事务无法控制MQ发送
- MQ失败无法回滚DB操作
- 导致数据不一致

---

### Q2: 事务同步器是什么？

**答案位置**：第四章 4.2节、第五章 5.4节

**核心要点**：
```java
TransactionSynchronizationManager.registerSynchronization(
    new TransactionSynchronization() {
        @Override
        public void afterCommit() {
            // ✅ 事务提交后才执行
            // 此时DB已持久化，数据不会丢失
            doAsyncInvoke(record);
        }
    }
);
```

---

### Q3: 如何避免重复拦截？

**答案位置**：第九章 9.5节

**核心要点**：
- 使用ThreadLocal标记
- 重试时设置标记，AOP检测到标记直接放行
- 避免无限循环拦截

```java
// AOP切面
if (SecureInvokeHolder.isInvoking()) {
    return joinPoint.proceed();  // 直接放行
}

// 重试执行
SecureInvokeHolder.setInvoking();  // 设置标记
method.invoke(bean, args);
SecureInvokeHolder.invoked();  // 清除标记
```

---

### Q4: 如何保证方法幂等性？

**答案位置**：第九章 9.3节

**核心方案**：
1. **唯一索引**：MQ消息设置唯一Key
2. **状态机**：检查状态，乐观锁更新
3. **分布式锁**：Redis锁防止并发

---

### Q5: 如何优化定时任务性能？

**答案位置**：第八章 8.3节、第九章 9.4节

**核心优化**：
1. **索引优化**：`idx_status_next_retry_time`
2. **分片查询**：按时间分片，避免全表扫描
3. **并发执行**：CompletableFuture并发处理
4. **流式查询**：分批处理，避免OOM

## 📝 核心知识点记录

### 问题：什么是本地消息表？

**答案**：
- 一张数据库表，存储第三方调用的方法信息
- 和业务数据在同一事务，保证持久化
- 定时任务扫描重试，保证最终执行成功

---

### 问题：核心原理是什么？

**答案**：
1. **持久化**：方法调用信息保存到DB
2. **事务同步器**：事务提交后异步执行
3. **定时重试**：失败自动重试（指数退避）
4. **反射调用**：序列化的方法信息反射执行

---

### 问题：如何实现通用化？

**答案**：
- 所有第三方调用本质都是Java方法
- 序列化：类名+方法名+参数类型+参数值
- 反射执行：`Class.forName().getMethod().invoke()`

---

### 问题：关键技术点有哪些？

**答案**：
1. **AOP切面**：`@Around("@annotation(secureInvoke)")`
2. **事务同步器**：`TransactionSynchronizationManager.registerSynchronization()`
3. **反射调用**：`Method.invoke(bean, args)`
4. **ThreadLocal**：避免重复拦截
5. **指数退避**：`Math.pow(2, retryTimes)`
