# 迁移总结文档

## 📋 执行概要

### 迁移决策
**选择方案**：LangChain4j
**理由**：
1. ✅ 支持当前 Spring Boot 2.6.7 + Java 8 环境
2. ✅ 功能比 Spring AI 更丰富（特别是 RAG）
3. ✅ 无需升级项目基础设施
4. ✅ 依赖稳定，可正常拉取
5. ✅ 社区活跃，文档完善

### 迁移范围
- 4 个 POM 文件
- 1 个配置文件
- 2 个新增 Java 类
- 2 个重构 Java 类
- 1 个测试类更新

### 预计工作量
- **总时间**：3-4 小时
- **风险等级**：低
- **回滚难度**：容易（保留原代码）

### 2. 配置变更

#### application-ai.yml

**变更前**：
```yaml
spring:
  ai:
    openai:
      api-key: ${OPENAI_API_KEY}
      chat:
        model: gpt-3.5-turbo
```

**变更后**：
```yaml
langchain4j:
  openai:
    api-key: ${OPENAI_API_KEY:}
    chat-model:
      model-name: gpt-3.5-turbo
    streaming-chat-model:
      model-name: gpt-3.5-turbo
    embedding-model:
      model-name: text-embedding-ada-002
```

### 4. API 映射

| 原 API (Spring AI) | 新 API (LangChain4j) | 说明 |
|-------------------|---------------------|------|
| `ChatClient.call()` | `ChatLanguageModel.generate()` | 同步调用 |

## 🆘 问题排查

### 常见问题

#### Q1: 依赖下载失败
**症状**：Maven 无法下载 LangChain4j 依赖

**解决方案**：
```bash
# 1. 检查 Maven 仓库配置
cat ~/.m2/settings.xml

# 2. 清理本地仓库
rm -rf ~/.m2/repository/dev/langchain4j

# 3. 强制更新
mvn clean install -U
```

#### Q2: API Key 无效
**症状**：调用 OpenAI API 返回 401 错误

**解决方案**：
```bash
# 1. 检查环境变量
echo $OPENAI_API_KEY

# 2. 重新设置
export OPENAI_API_KEY=sk-your-api-key

# 3. 或在配置文件中直接配置（不推荐）
langchain4j:
  openai:
    api-key: sk-your-api-key
```

#### Q3: 流式输出不工作
**症状**：流式接口返回空响应或一次性返回

**解决方案**：
```java
// 检查是否正确使用 StreamingChatLanguageModel
@Autowired
private StreamingChatLanguageModel streamingModel;  // 不是 ChatLanguageModel

// 检查是否正确实现 StreamingResponseHandler
new StreamingResponseHandler<AiMessage>() {
    @Override
    public void onNext(String token) {
        sink.next(token);  // 必须调用
    }
    // ...
}
```

#### Q4: Token 计数不准确
**症状**：Token 计数与实际消耗不一致

**说明**：
- `OpenAiTokenizer` 是估算值，误差 5-10% 是正常的
- 实际消耗以 OpenAI API 返回的 `usage` 字段为准

#### Q5: 编译错误
**症状**：找不到 LangChain4j 类

**解决方案**：
```bash
# 1. 确认依赖已添加
mvn dependency:tree | grep langchain4j

# 2. 重新导入项目（IDEA）
File -> Invalidate Caches / Restart

# 3. 重新编译
mvn clean compile
```
