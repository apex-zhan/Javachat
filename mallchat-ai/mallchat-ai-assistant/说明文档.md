# MallChat AI Assistant Module

智能助手模块，提供聊天内容总结和智能问答功能。

## Features

- **聊天内容总结**: 自动总结聊天记录，提取关键信息
- **智能问答**: 基于 LLM 的智能问答服务
- **流式输出**: 支持 SSE 流式响应，降低首字延迟
- **对话历史**: 自动保存对话记录到数据库
- **上下文管理**: 智能截断超长内容，保持在 token 限制内

## Quick Start

### 1. 配置

在 `application-ai.yml` 中添加配置：

```yaml
ai:
  assistant:
    summary:
      system-prompt: "你是一个专业的聊天内容总结助手。"
    qa:
      system-prompt: "你是一个智能助手。"
```

### 2. 使用 API

#### 聊天内容总结

```bash
curl -X POST http://localhost:8080/api/ai/assistant/summarize \
  -H "Content-Type: application/json" \
  -d '{
    "roomId": 123,
    "messageCount": 50
  }'
```

#### 智能问答

```bash
curl -X POST http://localhost:8080/api/ai/assistant/question \
  -H "Content-Type: application/json" \
  -d '{
    "userId": 1001,
    "question": "如何使用这个功能？"
  }'
```

### 3. 集成到项目

在 `mallchat-chat-server` 的 `pom.xml` 中添加依赖：

```xml
<dependency>
    <groupId>com.abin.mallchat</groupId>
    <artifactId>mallchat-ai-assistant</artifactId>
    <version>1.0-SNAPSHOT</version>
</dependency>
```

## Architecture

```
AIAssistantController (REST API)
    ↓
AIAssistantService (Business Logic)
    ↓
├─→ MessageDao (Chat Records)
├─→ LLMService (AI Generation)
└─→ AIConversationDao (History Storage)
```

## API Reference

### POST /api/ai/assistant/summarize

总结聊天内容（流式输出）

**Request Body**:
```json
{
  "roomId": 123,
  "messageCount": 50,
  "maxTokens": 4096
}
```

**Response**: `text/event-stream`

### POST /api/ai/assistant/question

智能问答（流式输出）

**Request Body**:
```json
{
  "userId": 1001,
  "question": "你的问题",
  "context": "可选的上下文",
  "roomId": 123
}
```

**Response**: `text/event-stream`
