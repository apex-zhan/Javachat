# MallChat AI LLM Module

## Overview

This module provides LLM (Large Language Model) integration for the MallChat AI system. It supports streaming and non-streaming chat completions using Spring AI framework.

## Features

- **LLM Service Interface**: Unified interface for different LLM providers
- **OpenAI Integration**: Full support for OpenAI GPT models with streaming
- **Retry Mechanism**: Automatic retry with exponential backoff for API failures
- **Token Counting**: Estimate token usage for prompts
- **Flexible Configuration**: Customizable temperature, max tokens, and other parameters

⚠️ **Dependency Issue:**

The Spring AI dependency is currently not resolving correctly:

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-openai-spring-boot-starter</artifactId>
    <version>1.1.3</version>
</dependency>
```

### Resolution Steps:

1. **Option 1: Use Spring AI Snapshot Repository**
   
   Spring AI is still in active development. Add the Spring snapshot repository to your Maven settings or parent POM:
   
   ```xml
   <repositories>
       <repository>
           <id>spring-snapshots</id>
           <name>Spring Snapshots</name>
           <url>https://repo.spring.io/snapshot</url>
           <snapshots>
               <enabled>true</enabled>
           </snapshots>
       </repository>
   </repositories>
   ```
   
   Then use the snapshot version:
   ```xml
   <spring-ai.version>1.0.0-SNAPSHOT</spring-ai.version>
   ```

2. **Option 2: Use Spring AI Milestone Repository**
   
   ```xml
   <repositories>
       <repository>
           <id>spring-milestones</id>
           <name>Spring Milestones</name>
           <url>https://repo.spring.io/milestone</url>
       </repository>
   </repositories>
   ```
   
   Check available versions at: https://repo.spring.io/milestone/org/springframework/ai/

3. **Option 3: Use Alternative LLM Library**
   
   If Spring AI is not available, consider using:
   - LangChain4j (https://github.com/langchain4j/langchain4j)
   - Direct OpenAI API client (https://github.com/TheoKanning/openai-java)

# Run unit tests only
mvn test -pl mallchat-ai/mallchat-ai-llm -Dtest=OpenAILLMServiceTest

## Configuration

Add the following to your `application-ai.yml`:

```yaml
spring:
  ai:
    openai:
      api-key: ${OPENAI_API_KEY}
      base-url: https://api.openai.com
      model: gpt-3.5-turbo
      connect-timeout: 30000
      read-timeout: 60000
      max-retries: 3
      retry-delay: 1000
```

## Usage Example

```java
@Autowired
private LLMService llmService;

// Streaming chat
Flux<String> stream = llmService.streamChat(
    "Explain quantum computing", 
    LLMOptions.defaultOptions()
);

stream.subscribe(chunk -> System.out.print(chunk));

// Non-streaming chat
String response = llmService.chat(
    "What is AI?",
    LLMOptions.summaryOptions()
);

// Count tokens
int tokens = llmService.countTokens("Hello, world!");
```
