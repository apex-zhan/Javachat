## 🔄 Migration Notice

### From Spring AI to LangChain4j

**Reason for Migration:**
- Spring AI requires Spring Boot 3.x + Java 17+
- Project uses Spring Boot 2.6.7 + Java 8 (cannot upgrade)
- LangChain4j supports Spring Boot 2.x + Java 8

**Key Changes:**
1. ✅ Dependencies: `spring-ai-openai-spring-boot-starter` → `langchain4j-open-ai`
2. ✅ Configuration: `spring.ai.*` → `langchain4j.*`
3. ✅ API: `OpenAiChatModel` → `ChatLanguageModel` + `StreamingChatLanguageModel`
4. ✅ Streaming: Direct Flux → Flux.create + StreamingResponseHandler
5. ✅ Token Counting: Custom estimation → OpenAiTokenizer

## Subtask 2.3: 实现 OpenAI LLM 适配器（流式支持）

**Status:** ✅ COMPLETED (Refactored for LangChain4j)

### Files Updated:

1. **`service/impl/OpenAILLMService.java`** 🔄 REFACTORED
   - Complete implementation of `LLMService` interface using LangChain4j
   
   - **Streaming Support:**
     - Uses `Flux.create()` to create reactive stream
     - Uses `StreamingChatLanguageModel.generate()` with callback handler
     - Implements `StreamingResponseHandler<AiMessage>`:
       - `onNext(String token)`: Emits each token immediately
       - `onComplete(Response<AiMessage>)`: Completes the stream
       - `onError(Throwable)`: Handles errors gracefully
     - Returns `Flux<String>` for immediate chunk delivery
   
   - **Non-Streaming Support:**
     - Uses `ChatLanguageModel.generate()` for complete responses
     - Validates response completeness
   
   - **Retry Logic:**
     - `@Retryable` annotation with exponential backoff
     - Max 3 attempts, 1s initial delay, 2x multiplier
     - Retries on `LLMApiException`
   
   - **Token Counting:**
     - Primary: Uses `OpenAiTokenizer.estimateTokenCountInText()`
     - Fallback: Simple estimation algorithm
       - Chinese: 1 char ≈ 1.5 tokens
       - English: 1 word ≈ 1.3 tokens
   
   - **Error Handling:**
     - Wraps all exceptions in `LLMApiException`
     - Logs errors with context
     - Provides meaningful error messages

### Code Example:

```java
// Streaming implementation with LangChain4j
@Override
public Flux<String> streamChat(String prompt, LLMOptions options) {
    return Flux.create(sink -> {
        streamingChatLanguageModel.generate(
            prompt,
            new StreamingResponseHandler<AiMessage>() {
                @Override
                public void onNext(String token) {
                    if (token != null && !token.isEmpty()) {
                        sink.next(token);
                    }
                }
                
                @Override
                public void onComplete(Response<AiMessage> response) {
                    sink.complete();
                }
                
                @Override
                public void onError(Throwable error) {
                    sink.error(new LLMApiException("Stream chat failed", error));
                }
            }
        );
    });
}
```

## Configuration Required

Add to `application-ai.yml`:

```yaml
langchain4j:
  openai:
    api-key: ${OPENAI_API_KEY}
    base-url: https://api.openai.com/v1  # Note: /v1 is required
    timeout: 60s
    max-retries: 3
    log-requests: true
    log-responses: false
    
    chat-model:
      model-name: gpt-3.5-turbo
      temperature: 0.7
      max-tokens: 2000
    
    streaming-chat-model:
      model-name: gpt-3.5-turbo
      temperature: 0.7
      max-tokens: 2000
```

**Important:** The `base-url` must include `/v1` suffix for LangChain4j.

## API Comparison

### Spring AI vs LangChain4j

| Feature | Spring AI | LangChain4j |
|---------|-----------|-------------|
| Sync Call | `ChatClient.call(prompt)` | `ChatLanguageModel.generate(prompt)` |
| Stream Call | `ChatClient.stream(prompt)` | `StreamingChatLanguageModel.generate(prompt, handler)` |
| Token Count | Custom implementation | `OpenAiTokenizer.estimateTokenCountInText(text)` |
| Configuration | `spring.ai.*` | `langchain4j.*` |
| Base URL | `https://api.openai.com` | `https://api.openai.com/v1` |
