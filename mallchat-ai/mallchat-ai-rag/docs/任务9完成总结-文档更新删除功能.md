## 关键技术点

### 1. 幂等删除机制
- 向量删除是幂等的（VectorService.deleteVectors）
- 多次删除同一文档返回一致结果
- 删除不存在的文档也返回成功

### 2. 原子性保证
- 使用@Transactional注解
- 删除操作在事务中执行
- 失败时自动回滚

### 3. 完整清理
- 删除向量数据（Milvus）
- 删除分块记录（MySQL）
- 删除文档记录（MySQL）

### 4. 更新流程
```
1. 查询旧文档
2. 幂等删除旧版本向量
3. 验证新文档
4. 保存新文档文件
5. 更新文档记录
6. 触发异步索引任务
```
