### Property 17: Chunk Metadata Completeness

**Validates**: Requirements 5.5

**Test Coverage**:

1. **Main Property Test** (`everyChunkShouldHaveCompleteMetadata`)
   - Verifies every chunk has metadata field
   - Verifies metadata can be deserialized from JSON
   - Verifies required fields are present:
     - `chunk_index` (not null, matches chunk index)
     - `source_location` (not null, >= 0)
     - `source_location_end` (not null, > source_location)
     - `create_timestamp` (not null, > 0)
     - `chunk_strategy` (not null, not empty)
   - Tests all chunking strategies (FIXED_SIZE, SEMANTIC, RECURSIVE, AUTO)

2. **Format Correctness** (`metadataShouldBeValidJson`)
   - Verifies metadata is valid JSON
   - Tests serialization/deserialization round-trip
   - Ensures no data loss during JSON conversion
   - Validates all fields match after round-trip

3. **Document Metadata Preservation** (`documentMetadataShouldBePreservedInChunks`)
   - Tests document-level metadata (documentId, title, type)
   - Verifies metadata is set on all chunks
   - Validates metadata consistency across chunks

4. **Source Location Validity** (`sourceLocationsShouldBeValid`)
   - Verifies source locations are within content bounds
   - Ensures source_location >= 0
   - Ensures source_location_end <= content.length()
   - Validates source_location < source_location_end

5. **Sequential Locations** (`sourceLocationsShouldBeSequential`)
   - Verifies source locations progress forward
   - Tests consecutive chunks have increasing locations
   - Ensures logical ordering of chunks

6. **Timestamp Validity** (`createTimestampsShouldBeValid`)
   - Verifies timestamps are recent and reasonable
   - Checks timestamps are within test execution window
   - Validates timestamp format (milliseconds since epoch)

7. **Strategy Consistency** (`chunkStrategyShouldMatchRequest`)
   - Verifies chunk_strategy matches requested strategy
   - Tests all strategy types (FIXED_SIZE, SEMANTIC, RECURSIVE, AUTO)
   - Validates AUTO strategy defaults to FIXED_SIZE

8. **Empty Content Handling** (`emptyContentShouldProduceNoChunks`)
   - Verifies empty content produces no chunks
   - Edge case testing

### Test Data Generators (Arbitraries)
