## 🚀 您需要做的操作

### 第一步：刷新 Maven 项目（必须）

**方法一：使用 IDEA 界面**
1. 点击 IDEA 右侧的 "Maven" 标签
2. 点击左上角的刷新图标（圆形箭头）
3. 等待依赖下载完成

**方法二：使用快捷键**
- Windows: `Ctrl + Shift + O`
- Mac: `Cmd + Shift + O`

**方法三：右键菜单**
- 右键点击项目根目录
- 选择 "Maven" → "Reload Project"

### 第二步：清理并重新编译（推荐）

在 IDEA 的 Terminal 中执行：

```bash
# 清理并编译
mvn clean compile -pl mallchat-ai/mallchat-ai-rag -am

# 或者安装到本地仓库
mvn clean install -DskipTests
```

### 第三步：使缓存失效并重启（如果还有红线）

如果刷新 Maven 后代码仍然有红色波浪线：

1. 菜单：`File` → `Invalidate Caches...`
2. 勾选以下选项：
   - ✅ Invalidate and Restart
   - ✅ Clear file system cache and Local History
3. 点击 "Invalidate and Restart"
4. 等待 IDEA 重启并重新索引（可能需要几分钟）

## 🔧 如果问题仍然存在

### 问题 A: 找不到 JetCacheUtils

**可能原因**：
- Maven 依赖没有下载完成
- IDEA 索引没有更新

**解决方案**：
1. 检查 Maven 工具窗口是否有错误提示
2. 手动下载依赖：
   ```bash
   mvn dependency:resolve
   ```
3. 重新索引：
   - `File` → `Invalidate Caches...` → `Invalidate and Restart`

### 问题 B: 编译错误 "无效的目标发行版: 17"

**可能原因**：
- IDEA 使用的 JDK 不是 Java 17

**解决方案**：
1. 打开 `File` → `Project Structure` → `Project`
2. 确保 "SDK" 选择的是 Java 17
3. 确保 "Language level" 是 17
4. 点击 "Apply" 和 "OK"

### 问题 C: 循环依赖警告

**可能原因**：
- `pom.xml` 中有不必要的依赖

**解决方案**：
检查并删除以下依赖（如果存在）：
```xml
<dependency>
    <groupId>com.abin.mallchat</groupId>
    <artifactId>mallchat-chat-server</artifactId>
    <version>1.0-SNAPSHOT</version>
    <scope>compile</scope>
</dependency>
```
