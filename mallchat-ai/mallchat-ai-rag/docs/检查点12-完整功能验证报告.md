#### 3.3 性能测试注意事项

**环境要求**:
1. 确保 Qdrant 向量数据库已启动（真实模式）
2. 确保 Ollama 已启动并拉取了 qwen2.5:14b 和 bge-large-zh-v1.5（真实模式）
3. 确保 MySQL 数据库已启动
4. 确保 Redis 已启动
5. 确保 RocketMQ 已启动

**测试前准备**:
```bash
# 启动 Qdrant
docker run -d --name qdrant -p 6333:6333 -p 6334:6334 qdrant/qdrant:latest

# 启动 Ollama
ollama serve
ollama pull qwen2.5:14b
ollama pull bge-large-zh-v1.5

# 启动 MySQL
docker-compose -f docker-compose-mysql.yml up -d

# 启动 Redis
docker-compose -f docker-compose-redis.yml up -d

# 启动 RocketMQ
docker-compose -f docker-compose-rocketmq.yml up -d
```

**性能优化建议**:
1. 如果 TTFB 超过 500ms，考虑：
   - 优化向量检索索引参数
   - 增加缓存层
   - 使用 Qdrant 连接复用

2. 如果向量检索延迟超过 100ms，考虑：
   - 调整 Qdrant 分片数量
   - 使用过滤条件减少搜索范围
   - 减少检索的 Top-K 数量

3. 如果文档索引速度低于 10 docs/min，考虑：
   - 增加 RocketMQ 消费者数量
   - 批量生成向量
   - 优化文档分块策略

4. 如果并发 QPS 低于 100，考虑：
   - 增加应用实例数量
   - 优化数据库连接池
   - 使用异步处理

5. 如果流式输出延迟超过 50ms/chunk，考虑：
   - 优化网络配置
   - 使用 HTTP/2
   - 调整 Ollama 推理参数
