#### 3.3 性能测试注意事项

**环境要求**:
1. 确保 Milvus 向量数据库已启动
2. 确保 MySQL 数据库已启动
3. 确保 Redis 已启动
4. 确保 RocketMQ 已启动
5. 确保 LLM API 可访问（OpenAI 或其他）

**测试前准备**:
```bash
# 启动 Milvus
docker-compose -f docker-compose-milvus.yml up -d

# 启动 MySQL
docker-compose -f docker-compose-mysql.yml up -d

# 启动 Redis
docker-compose -f docker-compose-redis.yml up -d

# 启动 RocketMQ
docker-compose -f docker-compose-rocketmq.yml up -d
```

**性能优化建议**:
1. 如果 TTFB 超过 500ms，考虑：
   - 优化向量检索索引参数
   - 增加缓存层
   - 使用连接池

2. 如果向量检索延迟超过 100ms，考虑：
   - 调整 Milvus 索引类型（IVF_FLAT → HNSW）
   - 增加 nprobe 参数
   - 减少检索的 Top-K 数量

3. 如果文档索引速度低于 10 docs/min，考虑：
   - 增加 RocketMQ 消费者数量
   - 批量生成向量
   - 优化文档分块策略

4. 如果并发 QPS 低于 100，考虑：
   - 增加应用实例数量
   - 优化数据库连接池
   - 使用异步处理

5. 如果流式输出延迟超过 50ms/chunk，考虑：
   - 优化网络配置
   - 减少每个 chunk 的大小
   - 使用 HTTP/2
