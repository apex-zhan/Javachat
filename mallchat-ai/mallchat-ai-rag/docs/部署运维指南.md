## 🚀 快速部署

### 步骤 1: 环境准备

#### 1.1 安装 Java 17

**Windows**:
```bash
# 下载 Amazon Corretto 17
# https://corretto.aws/downloads/latest/amazon-corretto-17-x64-windows-jdk.msi

# 配置环境变量
setx JAVA_HOME "C:\Program Files\Amazon Corretto\jdk17.x.x"
setx PATH "%PATH%;%JAVA_HOME%\bin"

# 验证
java -version
```

**Linux**:
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install openjdk-17-jdk

# CentOS/RHEL
sudo yum install java-17-openjdk-devel

# 验证
java -version
```

#### 1.2 安装 MySQL

```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE mallchat DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 导入表结构
mysql -u root -p mallchat < docs/ai-tables.sql
```

#### 1.3 安装 Redis

```bash
# Docker 方式（推荐）
docker run -d --name redis \
  -p 6379:6379 \
  redis:6.2-alpine \
  redis-server --appendonly yes
```

#### 1.4 安装 Milvus

```bash
# Docker Compose 方式
wget https://github.com/milvus-io/milvus/releases/download/v2.3.0/milvus-standalone-docker-compose.yml
docker-compose -f milvus-standalone-docker-compose.yml up -d
```

#### 1.5 安装 Ollama（Embedding 模型服务）

**推荐使用 Ollama 部署 bge-large-zh-v1.5 模型**

**Windows**:
```powershell
# 下载并安装 Ollama
# https://ollama.com/download

# 拉取 bge-large-zh-v1.5 模型
ollama pull bge-large-zh-v1.5

# 启动服务（默认端口 11434）
ollama serve
```

**Linux/macOS**:
```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 拉取 bge-large-zh-v1.5 模型
ollama pull bge-large-zh-v1.5

# 启动服务
ollama serve

# 验证服务
curl http://localhost:11434/api/tags
```

**Docker 方式**:
```bash
# 拉取 Ollama 镜像
docker pull ollama/ollama

# 启动容器
docker run -d --name ollama \
  -p 11434:11434 \
  -v ollama_data:/root/.ollama \
  ollama/ollama

# 进入容器拉取模型
docker exec -it ollama ollama pull bge-large-zh-v1.5

# 验证模型
docker exec -it ollama ollama list
```

**测试 Embedding 服务**:
```bash
# 测试 bge-large-zh-v1.5 模型
curl http://localhost:11434/v1/embeddings \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ollama" \
  -d '{
    "model": "bge-large-zh-v1.5",
    "input": "这是一段测试文本"
  }'
```


### 步骤 2: 配置文件

#### 2.1 application.yml

```yaml
spring:
  application:
    name: mallchat-ai-rag
  
  datasource:
    url: jdbc:mysql://localhost:3306/mallchat?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver
  
  redis:
    host: localhost
    port: 6379
    password: your_redis_password
    database: 0
    lettuce:
      pool:
        max-active: 20
        max-idle: 10
        min-idle: 5

# AI 配置
# 本地部署配置（推荐，使用 Ollama + bge-large-zh-v1.5）
ai:
  openai:
    # 本地 Ollama 服务地址
    api-key: ollama
    base-url: http://localhost:11434/v1
    model: gpt-3.5-turbo
    # 中文优化向量模型
    embedding-model: bge-large-zh-v1.5
    embedding-dimensions: 1024
  
  milvus:
    host: localhost
    port: 19530
    database: default
    collection-name: document_vectors
    # 向量维度必须与 embedding-model 一致
    dimension: 1024
  
  document:
    storage-path: /data/documents
    max-file-size: 52428800  # 50MB
    allowed-formats: pdf,docx,doc,txt,md,html
    use-oss: false
  
  rag:
    chunk-size: 500
    chunk-overlap: 50
    top-k: 5
    temperature: 0.7
    max-tokens: 2000

# RocketMQ 配置
rocketmq:
  name-server: localhost:9876
  producer:
    group: rag-producer-group
    send-message-timeout: 3000
  consumer:
    group: rag-consumer-group
    consume-thread-min: 5
    consume-thread-max: 10

# JetCache 配置
jetcache:
  statIntervalMinutes: 15
  areaInCacheName: false
  local:
    default:
      type: caffeine
      keyConvertor: fastjson
      limit: 1000
      expireAfterWriteInMillis: 300000
  remote:
    default:
      type: redis.lettuce
      keyConvertor: fastjson
      valueEncoder: kryo
      valueDecoder: kryo
      expireAfterWriteInMillis: 1800000
      poolConfig:
        minIdle: 5
        maxIdle: 20
        maxTotal: 50
```

#### 2.2 logback.xml

```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
        <encoder>
            <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>
    
    <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
        <file>logs/mallchat-ai-rag.log</file>
        <rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
            <fileNamePattern>logs/mallchat-ai-rag.%d{yyyy-MM-dd}.log</fileNamePattern>
            <maxHistory>30</maxHistory>
        </rollingPolicy>
        <encoder>
            <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>
    
    <root level="INFO">
        <appender-ref ref="CONSOLE"/>
        <appender-ref ref="FILE"/>
    </root>
    
    <logger name="com.abin.mallchat.ai.rag" level="DEBUG"/>
</configuration>
```

### 步骤 3: 编译打包

```bash
# 克隆代码
git clone https://github.com/your-repo/mallchat.git
cd mallchat

# 编译打包（跳过测试）
mvn clean package -DskipTests -pl mallchat-ai/mallchat-ai-rag -am

# 打包结果
# target/mallchat-ai-rag-1.0-SNAPSHOT.jar
```

### 步骤 4: 启动服务

```bash
# 方式1: 直接运行
java -jar mallchat-ai/mallchat-ai-rag/target/mallchat-ai-rag-1.0-SNAPSHOT.jar

# 方式2: 后台运行
nohup java -jar mallchat-ai/mallchat-ai-rag/target/mallchat-ai-rag-1.0-SNAPSHOT.jar > logs/app.log 2>&1 &

# 方式3: 使用 systemd（推荐）
sudo systemctl start mallchat-ai-rag
```

### 步骤 5: 验证部署

```bash
# 检查服务状态
```

### Nginx 反向代理配置

```nginx
upstream rag_backend {
    server 127.0.0.1:8080;
    server 127.0.0.1:8081;
    server 127.0.0.1:8082;
}

server {
    listen 80;
    server_name rag.example.com;
    
    location /api/ {
        proxy_pass http://rag_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        
        # SSE 支持
        proxy_set_header Connection '';
        proxy_http_version 1.1;
        chunked_transfer_encoding off;
        proxy_buffering off;
        proxy_cache off;
    }
}
```
