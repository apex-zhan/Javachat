## 🚀 快速部署

### 步骤 1: 环境准备

#### 1.1 安装 Java 17

**Windows**:
```bash
# 下载 Amazon Corretto 17
# https://corretto.aws/downloads/latest/amazon-corretto-17-x64-windows-jdk.msi

# 配置环境变量
setx JAVA_HOME "C:\Program Files\Amazon Corretto\jdk17.x.x"
setx PATH "%PATH%;%JAVA_HOME%\bin"

# 验证
java -version
```

**Linux**:
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install openjdk-17-jdk

# CentOS/RHEL
sudo yum install java-17-openjdk-devel

# 验证
java -version
```

#### 1.2 安装 MySQL

```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE mallchat DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 导入表结构
mysql -u root -p mallchat < docs/ai-tables.sql
```

#### 1.3 安装 Redis

```bash
# Docker 方式（推荐）
docker run -d --name redis \
  -p 6379:6379 \
  redis:6.2-alpine \
  redis-server --appendonly yes
```

#### 1.4 部署 Qdrant（推荐）

```bash
# Docker 方式
docker run -d \
  --name qdrant \
  -p 6333:6333 \
  -p 6334:6334 \
  -v $(pwd)/qdrant_storage:/qdrant/storage \
  qdrant/qdrant:latest

# 验证
curl http://localhost:6333
```

#### 1.5 安装 Milvus（备选）

```bash
# Docker Compose 方式
wget https://github.com/milvus-io/milvus/releases/download/v2.3.0/milvus-standalone-docker-compose.yml
docker-compose -f milvus-standalone-docker-compose.yml up -d
```

#### 1.6 安装 Ollama

**Windows**:
```powershell
# 下载并安装 Ollama
# https://ollama.com/download

# 拉取推荐模型
ollama pull qwen2.5:14b
ollama pull bge-large-zh-v1.5

# 启动服务（默认端口 11434）
ollama serve
```

**Linux/macOS**:
```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 拉取推荐模型
ollama pull qwen2.5:14b
ollama pull bge-large-zh-v1.5

# 启动服务
ollama serve

# 验证服务
curl http://localhost:11434/api/tags
```

**Docker 方式**:
```bash
# 拉取 Ollama 镜像
docker pull ollama/ollama

# 启动容器（GPU）
docker run -d --name ollama \
  -p 11434:11434 \
  -v ollama_data:/root/.ollama \
  --gpus all \
  ollama/ollama

# 进入容器拉取模型
docker exec -it ollama ollama pull qwen2.5:14b
docker exec -it ollama ollama pull bge-large-zh-v1.5

```

### 步骤 2: 配置文件

#### 2.1 创建 application-local.yml

推荐将本地/生产配置放在 `mallchat-chat-server/src/main/resources/application-local.yml`：

```yaml
# 激活本地 AI 配置
spring:
  profiles:
    active: local
  application:
    name: mallchat

# ==================== Embedding 配置 ====================
embedding:
  provider: bge   # 推荐: bge | 备选: m3e | 兼容: openai

ollama:
  base-url: http://localhost:11434
  embedding-model: bge-large-zh-v1.5
  timeout: 60s
  max-retries: 3

# ==================== 向量数据库配置 ====================
vector:
  store:
    provider: qdrant   # 推荐: qdrant | 备选: milvus

qdrant:
  host: localhost
  port: 6334
  api-key:              # 如无认证则留空
  collection-name: mallchat_knowledge
  grpc-timeout: 30
  use-tls: false

# Milvus 配置（备选，启用时取消注释）
# milvus:
#   host: localhost
#   port: 19530
#   database: default
#   collection:
#     name: mallchat_knowledge_vectors
#     dimension: 1024
#     index-type: IVF_FLAT
#     metric-type: COSINE
#     index-params:
#       nlist: 1024
#     search-params:
#       nprobe: 10

# ==================== LLM 配置 ====================
langchain4j:
  llm:
    provider: qwen        # 推荐: qwen | 备选: llama | 兼容: openai/chatglm
    fallback-provider: llama

ollama:
  base-url: http://localhost:11434
  model-name: qwen2.5:14b
  temperature: 0.7
  timeout: 120s

# ==================== 文档处理配置 ====================
document:
  allowed-formats: txt,md,html,pdf,docx,doc
  max-file-size: 10485760      # 10MB
  storage-path: ./uploads/documents
  use-oss: false

# ==================== RAG 配置 ====================
rag:
  retrieval:
    top-k: 5
    similarity-threshold: 0.7
    enable-rerank: false
```

```bash

  --spring.profiles.active=local \
  > logs/app.log 2>&1 &
```

#### 4.4 使用 systemd（推荐生产环境）

```ini
# /etc/systemd/system/mallchat-ai.service
[Unit]
Description=MallChat AI Service
After=network.target

[Service]
Type=simple
User=mallchat
WorkingDirectory=/opt/mallchat
ExecStart=/usr/bin/java -Xms4g -Xmx4g \
  -Dspring.profiles.active=local \
  -jar /opt/mallchat/mallchat-chat-server.jar
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable mallchat-ai
sudo systemctl start mallchat-ai
```

```nginx
upstream rag_backend {
    server 127.0.0.1:8080;
    server 127.0.0.1:8081;
    server 127.0.0.1:8082;
}

server {
    listen 80;
    server_name rag.example.com;
    
    client_max_body_size 20M;
    
    location /api/ {
        proxy_pass http://rag_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        proxy_http_version 1.1;
        chunked_transfer_encoding off;
        proxy_buffering off;
        proxy_cache off;

    }
}
```

## 🚨 常见问题

### Q1: 启动时提示 "No LLM service available"

**A**: 检查 `langchain4j.llm.provider` 配置是否正确，以及对应的服务 Bean 是否被正确加载。Mock 模式下需要设置 `spring.profiles.active=mock`。

### Q2: Qdrant 连接失败

**A**: 
1. 检查 Qdrant 是否已启动：`curl http://localhost:6333`
2. 检查 `qdrant.host` 和 `qdrant.port` 配置（注意 gRPC 端口默认是 6334）
3. 检查防火墙是否放行 6333/6334 端口

### Q3: Ollama 模型加载慢

**A**: 
1. 首次拉取模型需要下载，耐心等待
2. 使用量化版本减少显存占用：`qwen2.5:14b-q4_K_M`
3. 将模型预加载到显存：`ollama run qwen2.5:14b` 保持运行

### Q4: 文档索引失败

**A**: 
1. 检查 RocketMQ 是否正常运行
2. 查看 `DocumentIndexingConsumer` 日志
3. 检查文档格式是否在白名单内
4. 检查 Ollama Embedding 服务是否正常
