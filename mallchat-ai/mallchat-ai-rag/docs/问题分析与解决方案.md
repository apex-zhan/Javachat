## 问题分类

### 1. 编译环境问题

#### 问题描述
Maven编译时报错：`无效的目标发行版: 17`

#### 根本原因
- 项目配置要求 Java 17
- **当前系统使用的是 Java 8 (OpenJDK 1.8.0_452)**

#### 解决方案

**方案一：升级 Java 版本（推荐）**
```bash
# 下载并安装 Java 17
# Windows: 从 https://adoptium.net/ 下载 Temurin JDK 17
# 或使用 Amazon Corretto 17

# 配置环境变量 JAVA_HOME
# 指向 Java 17 安装目录

# 验证版本
java -version
```

**方案二：修改项目配置（临时方案）**
如果无法升级 Java，可以修改项目配置降级到 Java 8：
```xml
<!-- 在 pom.xml 中修改 -->
<maven.compiler.source>8</maven.compiler.source>
<maven.compiler.target>8</maven.compiler.target>
```

**注意**：降级到 Java 8 可能导致某些新特性无法使用。

#### 状态
❌ **已确认问题** - 系统使用 Java 8，项目需要 Java 17

### 2. 缓存类依赖问题

#### 2.1 DocumentMetadataCache

**问题描述**：
- 类已存在但可能存在依赖引用问题
- 使用了 `JetCacheUtils` 工具类

**当前状态**：✅ 已解决
- 类实现完整
- 依赖 `com.abin.mallchat.utils.JetCacheUtils`（位于 mallchat-cache-starter）
- 使用 JetCache 注解实现两级缓存

**功能说明**：
- 缓存文档元数据（标题、类型、大小等）
- 支持单个和批量查询
- 缓存时间：30分钟
- 缓存类型：BOTH（本地+Redis）

#### 2.2 IndexStatusCache

**问题描述**：
- 类已存在但可能存在依赖引用问题
- 使用 Redis 实现索引状态缓存

**当前状态**：✅ 已解决
- 类实现完整
- 依赖 `RedisTemplate<String, String>`
- 纯 Redis 缓存实现（不使用 JetCache）

**功能说明**：
- 缓存文档索引状态（PENDING, INDEXING, COMPLETED, FAILED）
- 支持单个和批量查询
- 缓存时间：10分钟
- 缓存类型：Redis（需要跨实例共享）

#### 2.3 QueryResultCache

**问题描述**：
- 类已存在但可能存在依赖引用问题

**当前状态**：✅ 已解决
- 类实现完整
- 依赖 `RedisTemplate<String, String>`
- 使用 Jackson 进行序列化

**功能说明**：
- 缓存热门查询的向量检索结果
- 缓存时间：5分钟
- 使用 MD5 哈希作为缓存键

## 问题解决总结

### 已解决的问题

1. ✅ **JetCacheUtils.create() 参数顺序错误**
   - **问题**：调用 `JetCacheUtils.create()` 时参数顺序错误
   - **位置**：`DocumentMetadataCache.java` 中的 3 处调用
   - **修复**：调整参数顺序为 `(name, cacheType, expire, cacheNullValue)`
   - **状态**：已修复

2. ✅ **缺少 mallchat-cache-starter 依赖**
   - **问题**：`pom.xml` 中缺少 `mallchat-cache-starter` 依赖
   - **影响**：导致 `JetCacheUtils` 类无法找到
   - **修复**：在 `mallchat-ai/mallchat-ai-rag/pom.xml` 中添加依赖
   - **状态**：已修复
