# 分块元数据管理实现总结

## 实现概述

本次实现完成了任务 4.4：实现分块元数据管理，为文档分块添加了完整的元数据支持，包括文档ID、分块序号、来源位置等信息。

## 实现内容

### 1. ChunkMetadata DTO (新增)

**文件**: `mallchat-ai/mallchat-ai-rag/src/main/java/com/abin/mallchat/ai/rag/domain/dto/ChunkMetadata.java`

**功能**:
- 定义分块元数据结构
- 包含字段：
  - `documentId`: 所属文档ID
  - `chunkIndex`: 分块序号
  - `sourceLocation`: 在原文档中的起始位置
  - `sourceLocationEnd`: 在原文档中的结束位置
  - `documentTitle`: 文档标题
  - `documentType`: 文档类型
  - `chunkStrategy`: 分块策略
  - `createTimestamp`: 创建时间戳
- 提供 JSON 序列化/反序列化方法

### 2. TikaDocumentProcessingService 增强

**文件**: `mallchat-ai/mallchat-ai-rag/src/main/java/com/abin/mallchat/ai/rag/service/impl/TikaDocumentProcessingService.java`

**更新内容**:

#### 2.1 chunkByFixedSize 方法
- 为每个分块创建 ChunkMetadata 对象
- 记录分块在原文档中的位置（start, end）
- 设置分块策略为 "FIXED_SIZE"
- 将元数据序列化为 JSON 并存储到 DocumentChunk.metadata 字段

#### 2.2 chunkBySemantic 方法
- 为语义分块添加元数据支持
- 跟踪段落在原文档中的位置
- 设置分块策略为 "SEMANTIC"
- 保存完整的位置信息

#### 2.3 setDocumentMetadata 方法（新增）
- 为分块列表批量设置文档级别的元数据
- 更新现有元数据或创建新元数据
- 设置 documentId, documentTitle, documentType
- 支持元数据的增量更新

### 3. DocumentProcessingService 接口扩展

**文件**: `mallchat-ai/mallchat-ai-rag/src/main/java/com/abin/mallchat/ai/rag/service/DocumentProcessingService.java`

**新增方法**:
```java
void setDocumentMetadata(List<DocumentChunk> chunks, Long documentId, 
                        String documentTitle, String documentType);
```

### 4. DocumentChunkDao 增强

**文件**: `mallchat-ai/mallchat-ai-common/src/main/java/com/abin/mallchat/ai/common/dao/DocumentChunkDao.java`

**新增方法**:
- `saveBatch(List<DocumentChunk> chunks)`: 批量保存分块
- `listByDocumentId(Long documentId)`: 根据文档ID查询所有分块
- `deleteByDocumentId(Long documentId)`: 根据文档ID删除所有分块
- `countByDocumentId(Long documentId)`: 统计文档的分块数量

## 使用示例

```java
// 1. 解析文档
String content = documentProcessingService.parseDocument(file);

// 2. 分块
List<DocumentChunk> chunks = documentProcessingService.chunkDocument(
    content, ChunkStrategy.FIXED_SIZE
);

// 3. 设置文档元数据
documentProcessingService.setDocumentMetadata(
    chunks, 
    documentId, 
    "文档标题", 
    "txt"
);

// 4. 保存到数据库
documentChunkDao.saveBatch(chunks);

// 5. 查询分块
List<DocumentChunk> savedChunks = documentChunkDao.listByDocumentId(documentId);

// 6. 解析元数据
for (DocumentChunk chunk : savedChunks) {
    ChunkMetadata metadata = ChunkMetadata.fromJson(chunk.getMetadata());
    System.out.println("Chunk " + metadata.getChunkIndex() + 
                      " at position " + metadata.getSourceLocation());
}
```

## 注意事项

1. **JSON 序列化**: 使用 Jackson 进行 JSON 序列化，确保项目中包含 Jackson 依赖
2. **数据库字段**: metadata 字段在数据库中定义为 JSON 类型，支持 MySQL 5.7+
3. **位置追踪**: sourceLocation 和 sourceLocationEnd 记录的是字符位置，不是字节位置
4. **事务支持**: 批量保存操作建议在事务中执行，确保数据一致性
