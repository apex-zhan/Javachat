### 2. 编译环境问题识别

#### 2.1 问题发现

执行 `mvn compile` 时发现错误：
```
[ERROR] Fatal error compiling: 无效的目标发行版: 17
```

#### 2.2 根本原因

- **系统 Java 版本**：Java 8 (OpenJDK 1.8.0_452)
- **项目要求版本**：Java 17
- **影响**：无法编译项目

#### 2.3 解决方案

**方案一（推荐）：升级到 Java 17**

优点：
- 可以使用所有新特性
- 符合项目设计要求
- 长期维护更好

步骤：
```bash
# 1. 下载 Java 17
# Windows: https://adoptium.net/
# Linux: sudo apt install openjdk-17-jdk

# 2. 配置环境变量
# Windows: 设置 JAVA_HOME 到 Java 17 安装目录
# Linux: export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64

# 3. 验证
java -version
# 应该显示 openjdk version "17.x.x"

# 4. 重新编译
mvn clean compile -pl mallchat-ai/mallchat-ai-rag -am
```

**方案二（临时）：修改项目配置降级到 Java 8**

缺点：
- 可能无法使用某些新特性
- 不符合项目设计
- 可能导致其他模块问题

步骤：
```bash
# 修改所有 pom.xml 中的配置
# 将以下内容：
<maven.compiler.source>17</maven.compiler.source>
<maven.compiler.target>17</maven.compiler.target>

# 改为：
<maven.compiler.source>8</maven.compiler.source>
<maven.compiler.target>8</maven.compiler.target>
```

**推荐**：使用方案一，升级到 Java 17。
